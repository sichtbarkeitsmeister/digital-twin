Digital Twin — Umgebungsvariablen zum Ausfüllen
================================================

WICHTIG
-------
• Diese Datei lokal ausfüllen. Die ausgefüllte Version NICHT ins Git committen.
• Dieselben Werte eintragen in:
  1) Vercel → Project digital-twin → Settings → Environment Variables → Production
  2) Claude Code Cloud → Umgebung „DigitalTwin“ → Umgebungsvariablen
• Keine Zeilen mit VERCEL_* aus „vercel env pull“ übernehmen.
• Keine Platzhalter wie [sensitive] — nur echte Werte.
• Format: NAME=wert (eine Zeile pro Variable, ohne Anführungszeichen)

Nach dem Speichern in Vercel: Production neu deployen (Deployments → Redeploy).

================================================================================
H) Supabase Datenbank — app_settings (SQL Editor, nicht Vercel)
================================================================================
Diese Werte stehen in der Tabelle public.app_settings — müssen zur App passen:

key                  | muss gleich sein wie
---------------------|------------------------------------------
app_base_url         | APP_BASE_URL (ohne Schrägstrich am Ende)
jobs_worker_token    | JOBS_WORKER_TOKEN (exakt derselbe Text)

Prüfen:
  select key, value from public.app_settings
  where key in ('app_base_url', 'jobs_worker_token');

Falls jobs_worker_token fehlt oder anders ist als JOBS_WORKER_TOKEN in Vercel,
Texte/Crawl/Jobs laufen nicht.
